# University Knowledge RAG Assistant

A simple Retrieval-Augmented Generation (RAG) system for answering questions from a controlled collection of documents.

**Status:** Stage 1 – Environment and project setup

## Planned Architecture

Documents → Loading → Cleaning → Chunking → Embeddings → Vector DB → Retrieval → LLM → Grounded answer → Sources

## Technologies

Python, Sentence Transformers, ChromaDB, Streamlit, PyPDF, Pytest
